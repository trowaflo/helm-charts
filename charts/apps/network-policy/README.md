# network-policy

![Version: 0.5.0](https://img.shields.io/badge/Version-0.5.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square)

Helm chart for Cilium network policies of one namespace. Puts every pod of the
namespace in default deny, then opens only the flows the app declares: Kubernetes
API, Internet, FQDNs, CIDRs and pods, each with the reason it exists. Flows shared
by every app (DNS, gateway, scrape) belong to a cluster-wide baseline, not here.

## Values

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| fullnameOverride | string | `""` | Override the full resource name prefix. |
| nameOverride | string | `""` | Override the chart name in resource names. |
| networkPolicy.egress | list | [] (only the baseline applies) | Outbound flows of this namespace, one entry per need, beyond the cluster-wide baseline (DNS, gateway hairpin). Every entry carries `why`, rendered as the policy `description`. Templates live in the common library (3.2.0). Entry keys: - `to`: `kube-apiserver`, `world`, `fqdn`, `cidr` or `pods`. - `select`: matchLabels of the local pods the rule applies to; empty = every pod. - `ports`: required for `world`, `cidr` and `pods`; 6443 for `kube-apiserver`,   443 for `fqdn` when omitted. - `protocol`: `TCP` (default), `UDP` or `ANY`, for every port of the entry. - `names`: FQDNs, for `fqdn`; the DNS of the selected pods then goes through the   Cilium DNS proxy, which learns the IPs behind the names. - `cidrs`: CIDRs, for `cidr`. - `namespace`, `selector`: peer pods, for `pods`; namespace defaults to the release   namespace, an empty selector means every pod of that namespace. A peer in the   same namespace also gets the matching ingress, so one entry opens both sides. - `why`: required, one sentence. ```yaml networkPolicy:   egress:     - to: pods       select: {app.kubernetes.io/name: authentik}       selector: {app.kubernetes.io/name: postgresql}       ports: [5432]       why: Server and worker store users, flows and sessions.     - to: fqdn       select: {app.kubernetes.io/name: grafana}       names: [grafana.com]       why: Update check. ``` |
| networkPolicy.enabled | bool | `true` | Render the policies; this chart exists for that, unlike the common library where the default is false. |
| networkPolicy.ingress | list | [] (only the baseline applies) | Inbound flows of this namespace from other namespaces or CIDRs. The gateway and Prometheus are allowed by the cluster-wide baseline; a peer in the same namespace is opened by its `egress` entry. Entry keys: - `from`: `pods` or `cidr`. - `select`: matchLabels of the local pods that receive the flow; empty = every pod. - `namespace`, `selector`: peer pods, for `pods`; namespace defaults to the release   namespace. - `cidrs`: CIDRs, for `cidr`. - `ports`, `protocol`, `why`: as for `egress`; `ports` is required. ```yaml networkPolicy:   ingress:     - from: pods       namespace: homepage       selector: {app.kubernetes.io/name: homepage}       select: {app.kubernetes.io/name: grafana}       ports: [3000]       why: Homepage widget reads Grafana. ``` |
